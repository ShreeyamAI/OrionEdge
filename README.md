# OrionEdge Website

A website presenting OrionEdge and its stated proprietary-trading focus.

## Sections

- Introduction and company information
- Trading philosophy
- YouTube section
- Frequently asked questions
- Contact form and social links

## Built With

HTML, CSS, and JavaScript.

## Run Locally

Open `website-main/website-main/index.html` in a browser.

## Contact Form

The current page is configured to submit its contact form to Formspree. Review the form settings before publishing or collecting submissions.
